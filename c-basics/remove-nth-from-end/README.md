# remove-nth-from-end：刪掉倒數第 n 個節點

## 題目

LeetCode 19。單向鏈結串列，刪掉**倒數**第 `n` 個節點（`n = 1` 是最後一個），回傳刪完之後的頭。

```sh
make test   # 一開始 RED 0/8，全綠＝過關（ASan 會抓 leak：刪掉的節點要 free）
```

只改 `remove_nth.c`；規格在 `remove_nth.h`，保證 `1 <= n <= 長度`。

**挑戰**：只准走**一趟**（不准先數長度再走第二趟）。測試抓不到這條，靠你自己守。

## 為什麼插隊

## Java 你會怎麼寫（兩趟版）

```java
int len = 0;
for (Node p = head; p != null; p = p.next) len++;
// 再走一次，停在要刪的前一個……
```

C 版的一趟解法，跟 Java 沒有差別——難的是**指標要停在哪裡**。

## 你以前卡過的點（先自己檢查）

| 弱點 | 這題會出現在哪 |
|------|------|
| 回傳值＝呼叫完之後的頭 | 刪頭時 `head` 會變 |
| `free` 要傳節點，不是資料 | `free(victim)` 不是 `free(victim->val)` |
| 先抓住 `next` 再 `free` | 不然 use-after-free |
| off-by-one：第幾個 vs 離起點幾步 | 第 3 題的「晚幾步」 |
| 該寫當下節點卻寫成頭 | 移動的是你的指標，不是 `head` |
