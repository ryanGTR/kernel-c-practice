& 與 *：查門牌、照門牌走

記憶體是一整排格子，每格都有門牌號碼，也就是位址。C 的指標只是一個「裡面放門牌」的格子。這頁只要記兩件事：

&查門牌：&x 是 x 的位址，x 不動 *照門牌走：*p 是 p 指到的那格

每段按「下一步」播放。藍色的是門牌（位址）在移動，橘色圓點是 * 正在照門牌走。右邊的格子依位址由小到大往下排，箭頭代表「這格裡放的是那格的門牌」。

第 6 課

宣告裡的 * 不是在走門牌

int *p 的 * 只是在說「p 是指向 int 的指標」。宣告時後面的 = 給的是 p 本身，不是 *p。

錯：門牌寫成 1 
int *p = 1;

意思是「p 的門牌是 1」，不是「p 指到的格子放 1」。位址 1 不是你的，-Werror 會直接擋下。

錯：沒門牌就去寫 
int *p;
*p = 1;

p 還是垃圾值，照著亂寫的門牌去寫，程式可能直接當掉，也可能悄悄寫壞別人的資料。

對：先有格子，再給門牌 
int x;
int *p = &x;
*p = 1;   /* x == 1 */

先宣告 x，把 x 的門牌交給 p，再照門牌把 1 寫進去。

自我檢查

先答再打開

接續第 5 課的狀態：x = 9、z = 7、p 指向 z、pp 指向 p。

Q1　*pp 的值是什麼？**pp 呢？

*pp 是 p 裡的門牌 0x104（z 的位址）。**pp 再走一次，到 z，是 7。

Q2　執行 p = &x; 之後，*pp 變成什麼？

0x100。pp 指的是 p 這格，p 的內容換了，所以 *pp 跟著變。

Q3　int *q = *pp; 之後 *q = 1，改到誰？

右邊 *pp 是讀，讀出 p 的門牌。若 p 指向 z，q 也指向 z，*q = 1 就把 z 改成 1。

Q4　void f(int *a) { a = NULL; } 呼叫 f(p) 後，p 變 NULL 嗎？

不會。a 是 p 的複本，改 a 只換掉複本裡的門牌。要改到 p，參數要是 int **，寫 *a = NULL，呼叫 f(&p)。
